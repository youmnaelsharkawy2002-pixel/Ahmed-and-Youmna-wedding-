PUBLISH:
1. Extract this ZIP.
2. Upload index.html and the entire assets folder to a new GitHub repository.
3. Sign in to Vercel with GitHub, import the repository, then click Deploy.
4. Share the Vercel URL once deployed.

MUSIC:
The site includes a music toggle but does not include a song file. If you want music, add an MP3 you have permission to use, name it wedding-song.mp3, and place it in assets. Browsers generally require the visitor to tap before music starts.

LOCATION:
The map button searches for the supplied venue name/address. Please verify the exact map pin before sending the invitation.
